

# WEEK 6 – LLM Evaluation

## 1. Aim

To evaluate the performance of the Llama 3.2 Large Language Model by asking predefined questions, comparing its answers with expected answers, and calculating keyword-based evaluation scores.

## 2. File Name

`Week6_LLM_Evaluation.ipynb`

## 3. Description

This experiment implements a baseline evaluation system for a Large Language Model using Ollama and Llama 3.2.

The notebook installs Ollama, starts the Ollama server, downloads the Llama 3.2 model, and creates a Golden Question Set containing 30 questions related to Generative AI and Large Language Models.

The model generates answers for each question. The program compares the generated answers with predefined expected keywords and calculates a keyword coverage score.

Finally, the evaluation results are saved in CSV and JSON files.

## 5. Implementation Steps

1. Import the required Python libraries:
   - `os`
   - `sys`
   - `time`
   - `json`
   - `csv`
   - `subprocess`
   - `requests`
   - `datetime`

2. Install Ollama using the installation script.

3. Start the Ollama server using the `ollama serve` command.

4. Download the Llama 3.2 model using:
   ```bash
   ollama pull llama3.2
   ```

5. Create a Golden Question Set containing 30 questions, expected answers, keywords, and reference sources.

6. Define the `get_llm_answer()` function to send questions to the Llama 3.2 model through the Ollama API.

7. Define the `calculate_score()` function to compare generated answers with expected keywords.

8. Run the baseline evaluation for all 30 questions.

9. Calculate matched keywords, missing keywords, scores, and evaluation status.

10. Save the evaluation results in:
    - `baseline_results.csv`
    - `golden_set.json`

11. Generate the final baseline evaluation summary.

### Output 5: Baseline Evaluation

**Purpose:** Sends all 30 questions to Llama 3.2 and evaluates the generated answers.

For every question, the program displays:

- Question ID
- Question
- LLM-generated answer
- Expected answer
- Matched keywords
- Missing keywords
- Keyword coverage score
- Evaluation status

**Example from the actual notebook:**

```text
Question 1: Q001

Question:
What is tokenization in large language models?

Matched Keywords: ['splitting', 'text', 'tokens']
Missing Keywords: []

Score: 100.0 %
Status: PASS
```

**Explanation:** The generated answer contains all three expected keywords. Therefore, the keyword coverage is 100%, and the question receives a PASS status.

The program uses the following scoring method:

```text
Keyword Coverage =
(Matched Keywords / Total Expected Keywords) × 100
```

A score of 60% or above is marked as PASS. A score below 60% is marked as REVIEW.
